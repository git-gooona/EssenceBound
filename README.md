# EssenceBound
A 2D game I'm developing in Python as I learn game programming and software engineering.

## Current Version
v0.5 - In Development

## About
It's a turn based card game roguelike built off the CMU graphics library in which your cards are spells and you cast them while progressing
through a dungeon. I'm adding things like equipment and consumable items to make it as RPG-like as possible.

Most of this was developed when I was in high school, so the code isn't the best. I'm currently updating the file format and structure
to make it easier to continue development and to improve scalability.

## Controls
- M to open the map
- WASD or arrow keys for movement (only on the map)
